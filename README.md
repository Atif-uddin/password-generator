# Random Password Generator

A simple and responsive Random Password Generator built using React and Tailwind CSS.  
This application generates secure random passwords with customizable options like uppercase letters, lowercase letters, numbers, and symbols.

---

## Features

- Generate random secure passwords
- Adjustable password length
- Include/exclude:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- One-click password copy
- Responsive UI
- Instant password regeneration

---

## Tech Stack

- React
- Tailwind CSS
- JavaScript
- Vite
